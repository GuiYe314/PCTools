# 聚点工作台

仓库现在还包含独立的 `JuDianFileShare.Server` 局域网 Web 文件共享服务。它暂未嵌入 WPF 左侧导航，启动与配置方法见仓库根目录 `README.md`。

首个可运行版本包含：

- WPF 桌面基础框架、单实例、全局异常记录和本地持久化
- 文件夹登记、编辑、搜索、收藏、路径检查、打开和复制路径
- 文件夹目录树延迟加载
- 文件夹详情提供“读取文件夹”，保存读取时间与 Unity 项目识别结果；只有确认存在 Unity 项目后才显示打开按钮
- 文件夹管理可向下识别 Unity 项目，读取项目 Editor 版本并使用匹配的 Unity Editor 打开；检测到多个项目时可弹窗选择
- 任务添加、弹窗编辑、搜索、勾选完成、四种状态、处理注释和文件夹关联
- 文件夹操作仅写入运行日志，不混入任务列表
- 文件夹列表项可直接打开目录
- 工作台收藏文件夹条目尾部提供“打开文件夹”按钮
- 任务状态使用下拉菜单：未完成、已完成、无法完成、已丢弃
- 根据任务标签自动生成分类筛选
- 任务支持归档、归档查看和恢复
- 任务显示计划日期、计划时间和创建时间
- 文件夹支持分类、路径状态、收藏筛选和批量路径检查
- 设置页支持每日自动备份、保留数量、手动备份与恢复
- 任务支持截止时间、完成时间、逾期提示和一次性提醒
- 任务支持带独立备注的子任务清单，并显示完成进度
- 任务支持每天、每周、每月、每年的重复周期、间隔和可选结束日期；当前周期完成后自动生成下一期
- 任务页提供提醒视图，可筛选全部、逾期、未来 7 天和已提醒任务
- 命令中心可把 CMD 命令、软件路径和 BAT/CMD 脚本保存为分类按钮，一键执行
- 快捷命令支持启动参数、工作目录、管理员权限、执行前确认、命令窗口保留，以及执行次数和最后执行时间记录
- 文件夹、任务和命令中心支持自定义快捷筛选标签；可组合分类、数据标签、状态和模块专属条件并固定到页面，单击筛选、右键编辑或删除，并可固定/取消固定、拖动或按钮排序
- GitHub 热门项目按近 7/30/90 天和开发语言检测近期高星仓库
- GitHub 榜单保存上次快照，标记新上榜、排名上升、热度上升，并支持项目搜索、详情、打开仓库和复制克隆地址
- GitHub 项目说明支持一键翻译为中文、原文/中文切换，并缓存翻译结果
- 界面启用 Per-Monitor V2 DPI 感知、ClearType、布局取整，并避免对文字容器应用位图阴影，改善高缩放屏幕的字体清晰度
- 设置页支持修改软件显示名称，并同步更新窗口标题、左上角名称和首字图标
- 功能管理弹窗可显示或隐藏左侧的工作台、文件夹、任务、命令中心、GitHub、系统与网络入口；隐藏功能不会删除数据
- 目录结构同时显示文件夹和文件，单击名称即可打开
- 全局采用圆角按钮、输入框、卡片阴影、列表悬停与选中高亮
- “系统与网络”可检测本地网络与互联网、查看电脑配置、网卡、本地/公网 IP、所在地和运营商
- 记住最后选择的网卡，下次打开时自动恢复；网卡不存在时回退到当前已连接网卡
- 支持将指定网卡切换为 DHCP 或静态 IPv4；静态参数先校验，实际应用时需要 Windows 管理员确认

## 功能测试

`JuDianWorkbench.FunctionalTests` 覆盖文件夹收藏与筛选、备份恢复、任务归档恢复、状态持久化、标签分类、提醒去重和命令中心持久化与校验。

## 运行

```powershell
dotnet run --project .\JuDianWorkbench.csproj
```

数据保存在 `%LOCALAPPDATA%\JuDianWorkbench\data.json`，日志保存在 `%LOCALAPPDATA%\JuDianWorkbench\Logs`。

目前持久化层采用无外部依赖的 JSON 原子写入实现，并通过独立服务封装；后续可以替换为 SQLite，而不影响界面层和业务模型。
